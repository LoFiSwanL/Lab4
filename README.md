Задача
Розробити структуру даних для багатопотокової програми, що складається з m
цілих полів, які можна читати та змінювати (кожне окремо).
Для кожного поля мають бути операції добування та встановлення значення, а також
для структури в цілому перевантажений operator string.
Структура даних має бути оптимізована під такі обмеження:
для кожного поля відомий % операцій (від усіх операцій з структурою даних)
добування та встановлення значення, а також відомий % запитів рядка.
